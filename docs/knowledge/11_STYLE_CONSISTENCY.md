# 11 — Cohérence stylistique

## Style lock
Pour un personnage existant, garder :
- palette,
- épaisseur des contours,
- niveau de détail,
- shading,
- géométrie,
- proportions,
- taille des yeux,
- coiffure/fourrure,
- accessoires.

## Pas de mélange involontaire
Ne pas combiner :
- tête semi-réaliste + corps flat,
- main détaillée + bras ultra-géométrique,
- ombrage complexe sur une seule pièce,
- contours noirs sur une partie seulement.

## Silhouette
L'action doit rester lisible en silhouette.
Éviter les superpositions qui rendent bras/jambes indéchiffrables.

## Densité de détail
Le détail doit rester compatible avec la taille finale de rendu.
