# Prompt d'agent — import d'un personnage

Tu reçois un ensemble d'assets 2D. Ta mission est de construire un package Character conforme au schéma.

Procédure :
1. identifier le type : human/quadruped/creature;
2. identifier les vues;
3. lister les parties sémantiques;
4. détecter les variantes (mains, visages, vues);
5. proposer les pivots;
6. proposer le z-order;
7. sélectionner un rigProfile;
8. mapper parts → slots → bones;
9. lister les expressions;
10. lister les clips possibles;
11. signaler tout asset manquant.

Ne fabrique pas silencieusement une partie absente.
