# Checklist d'import d'un personnage

- [ ] ID unique
- [ ] styleProfile défini
- [ ] rigProfile défini
- [ ] vue principale définie
- [ ] parts nommées sémantiquement
- [ ] assets existants
- [ ] alpha réel si raster
- [ ] pivots placés sur articulations
- [ ] z-order cohérent
- [ ] overlap suffisant aux joints
- [ ] bones sans cycle
- [ ] slots valides
- [ ] limites articulaires définies
- [ ] expressions mappées
- [ ] poses minimales testées
- [ ] rendu front sans trou
- [ ] IK bras/jambes testée
- [ ] identité visuelle stable
